# YoIndie releases

Downloads for YoIndie's Mac apps. One folder per product; each version's disk image is attached
to a GitHub release tagged `<product>-v<version>`, for example `macdrop-v1.0.0`.

| Product | Folder | Latest download |
| --- | --- | --- |
| MacDrop | [`macdrop/`](macdrop/) | [yoindie.com/download/macdrop](https://yoindie.com/download/macdrop) |

Buying a product, its license and support are at [yoindie.com](https://yoindie.com). The apps
update themselves: each checks YoIndie for a newer version and installs it from here.

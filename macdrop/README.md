# MacDrop

The top of your Mac's screen, made useful: hover there and MacDrop opens into a panel for the
things you check all day. [yoindie.com/products/macdrop](https://yoindie.com/products/macdrop)

- **Download:** [yoindie.com/download/macdrop](https://yoindie.com/download/macdrop) always
  points at the newest version. Every version is under
  [Releases](https://github.com/YoIndie/releases/releases?q=macdrop), tagged `macdrop-v<version>`.
- **Requires:** macOS 14 or later.
- **License:** activate with the key from your purchase email. One license, one Mac.
- **First launch:** macOS may say it cannot check the developer. Open System Settings →
  Privacy & Security and click **Open Anyway**. You only do this once; updates install
  without asking again.
